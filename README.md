# <img src="/assets/images/logo.png" width="28px"> Issue Proxy Bot

A streamlined solution for collecting GitHub issues from users who don't use or know how to use GitHub.

## Overview

Issue Proxy Bot provides a user-friendly form for submitting issues to GitHub repositories. It bridges the gap between end-users and developers by offering a simplified submission process outside of GitHub's interface.

## Key Features

- **Simple Submissions**: Custom forms that don't require GitHub accounts
- **Moderation Support**: Optional review process before issues are created
- **Flexible Deployment**: Deploy on Cloudflare Workers or other platforms
- **Customizable Forms**: Adapt report forms' UI however you'd like it to be

## Use Cases

- Products with non-technical users who need to report bugs
- Open source projects looking to lower the barrier for feedback
- Organizations that want to streamline issue reporting
- Developers who want to provide anonymous issue submission

## Implementation Options

- **Web Form**: Use the pre-built SvelteKit web interface
- **Headless**: Integrate the API with your own custom UI forms
